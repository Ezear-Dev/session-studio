Built on the work of others
---------------------------
* SessionOpenMP, by matsix (GPL-3.0), https://github.com/matsixx/SessionOpenMP
  The file third_party/ue4ss_abi/ue4ss_abi.h, a declaration of RE-UE4SS 3.0.1's RC::CppUserModBase class,
  comes from SessionOpenMP (see also the RE-UE4SS notice below). Session Anim Loader's multiplayer uses
  SessionOpenMP's mod channel when SessionOpenMP is installed; SessionOpenMP itself is not part of this package.
* ExpandedTricksNative, by Portman2 (GPL-3.0)
  The way the pose hook is installed (vtable slot, offsets, order of the chain) comes from it.
  ExpandedTricks itself is not part of this package.

Session Studio is inspired by Skate Style's Animation Studio (ideas only, no code and no asset).


RE-UE4SS 3.0.1 -- https://github.com/UE4SS-RE/RE-UE4SS
------------------------------------------------------
The package contains UE4SS.dll and dwmapi.dll from the official UE4SS_v3.0.1.zip, unchanged, and its
UE4SS-settings.ini with four values changed (engine version 4.27, developer console window off, no offset dump). None of the Lua mods
of that zip is included. The native mod links against UE4SS.dll.
