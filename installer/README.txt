Session Studio v0.31 and Session Anim Loader v0.31
Animation tools for Session: Skate Sim (Windows, Steam). Unofficial fan project, work in progress.

INSTALL OR UPDATE
  1. Extract the WHOLE zip into a normal folder.
  2. Close the game and Session Studio.
  3. Double-click INSTALLER.cmd and follow the questions.
  4. Start the game, put the skater on the board, wait about 10 seconds, then open Session Studio.

The installer puts UE4SS 3.0.1 in place only if you do not have UE4SS yet. It never deletes your clips.

No animation is included. Do a move once in game (its original movement is recorded), then edit it in Session Studio.

UNINSTALL
  Close the game and Session Studio, then double-click UNINSTALL.cmd. It removes only what the installer added, and
  moves your clips to Documents\SessionStudio instead of deleting them.

Everything else (copying by hand, troubleshooting): INSTALL.html (or INSTALL.md).
Guides: after installing, the "docs" folder next to SessionStudio.exe.

Thanks to matsix (SessionOpenMP) and Portman2 (ExpandedTricks): their work helped us a lot.
